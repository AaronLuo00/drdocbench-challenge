Scoring contract

Dr.DocBench Document Parsing Evaluator

drdocbench-document-parsing-v1

Prediction unit

Every manifest identifier (subject, document_id, start_page, end_page) must occur exactly once. Missing, extra, or duplicate windows fail structural validation.

Metrics

  • Text ED: normalized Levenshtein distance over scored text categories, 0-1; lower is better.
  • Table TEDS: mean valid-table similarity, displayed on 0-100; higher is better.
  • Formula CDM: mean isolated-formula CDM F1, displayed on 0-100; higher is better.
  • Reading Order: (1 - normalized edit distance) * 100; higher is better.

Overall

WindowOverall(w) = mean(available 0-100 components in w)
Overall          = mean(WindowOverall(w) for every scorable window w)

Unavailable components are excluded, not assigned zero. Windows with no supported component are excluded from every metric denominator.

Phase manifest audit

  • Public Validation v1: 67 documents, 1,005 pages, and 938 required identifiers; 900 are scorable and 38 are non-scorable.
  • Private Test v2: 34 held-out documents, 509 released pages, and 474 required identifiers; 454 are scorable and 20 are non-scorable.

Non-scorable windows contain only figures, figure captions, masks, figure footnotes, page numbers, or no layout detections. They are required for structural completeness but do not affect any score. Private Test v2 also excludes one empty annotation page for which no input image was provided, and no window crosses that page-number gap.

Formula syntax

The Markdown parser accepts $ ... $ or \( ... \) inline, and $$ ... $$ or \[ ... \] for display formulas. The current GT primarily uses dollar delimiters in text and Pandoc-style \( ... \) spans inside some structured HTML tables. Table cell contents are preserved as submitted and compared by TEDS.
