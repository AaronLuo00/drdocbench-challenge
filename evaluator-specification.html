Scoring contract

Dr.DocBench Document Parsing Evaluator

drdocbench-document-parsing-v3-single-page-md2md

Prediction unit

Every manifest identifier (subject, document_id, page) must occur exactly once. Missing, extra, or duplicate pages fail structural validation.

Ground-truth source

The production reference is the curated per-page Markdown in mds/*.md. For every required page, the evaluator reads exactly <document_id>_<page>.md. The reference and submitted single-page Markdown are parsed and matched through the same evaluation path. Private structured annotations are retained for auditing and regression diagnostics.

Visual-region policy

  • Readable labels for ordinary diagrams and figures are scored when transcribed as standalone reference text.
  • The complete dense map region on Sports page 14, including its individual map labels, is intentionally excluded from scoring.
  • Individual letters inside Games & Activities puzzle grids are intentionally excluded. Separately transcribed puzzle headings and instructions remain scoreable.
  • Markdown image nodes and relative ./imgs/* crop references are ignored. The evaluator never opens those crop files, and participants do not submit them.

Metrics

  • Text ED: normalized Levenshtein distance over scored text categories, 0-1; lower is better.
  • Table TEDS: mean valid-table similarity, displayed on 0-100; higher is better.
  • Formula CDM: mean isolated-formula CDM F1, displayed on 0-100; higher is better.
  • Reading Order: (1 - normalized edit distance) * 100; higher is better.

Overall

PageOverall(p) = mean(available 0-100 components on p)
Overall        = mean(PageOverall(p) for every scorable page p)

Unavailable components are excluded, not assigned zero. Pages with no supported component are excluded from every metric denominator.

Public Validation manifest audit

  • Public Validation: 34 documents and 509 required page predictions; 487 are scorable and 22 are non-scorable.

A non-scorable page contains no Text, Table, Formula, or Reading Order component after its reference Markdown is parsed. It is required for structural completeness when an input image is released but does not affect any score. The shared evaluation set excludes one empty reference page for which no input image was provided.

Public Validation is the challenge's only official participant-facing phase. Eligible results may appear on the public leaderboard.

The official evaluation unit is one page. The previous adjacent two-page-window design and its 474-window manifest are retired and are not used by this challenge.

Formula syntax

The Markdown parser accepts $ ... $ or \( ... \) inline, and $$ ... $$ or \[ ... \] for display formulas. The current GT primarily uses dollar delimiters in text and Pandoc-style \( ... \) spans inside some structured HTML tables. Table cell contents are preserved as submitted and compared by TEDS.
