Overview

The Dr.DocBench Challenge focuses on expert-level document parsing at the intersection of document recognition, layout understanding, and structured extraction. Based on Dr.DocBench, it uses difficulty-aware data selected around cases where strong document parsers struggle.

Participants will recover structured content from complex document pages, including text, tables, formulas, reading order, and specialized notation. The challenge is part of the DocInsights 2026 workshop at EMNLP 2026.

Dataset

The challenge uses a dedicated subset of Dr.DocBench prepared for expert-level document parsing. Public development data will be released through Hugging Face.

The dataset link, documentation, and final release details will be added when available.

Evaluation

Submissions will be evaluated using document-parsing metrics aligned with Dr.DocBench. The final metric set and aggregation formula will be published with the evaluator.

Text Edit Distance

Measures text-recognition accuracy. Lower is better.

Table TEDS

Measures table structure and content similarity. Higher is better.

Formula CDM

Measures mathematical-formula recognition. Higher is better.

Reading Order

Measures whether document elements appear in the correct sequence. Higher is better.

Overall

Combines the evaluation metrics to determine the ranking.

Submission

Structured Predictions
